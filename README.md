# Školski IT klub

Jednostavna responzivna prezentacijska stranica zamišljenog školskog IT kluba. Izrađena je pomoću HTML-a, CSS-a i JavaScripta kao školski projekt.

## Sadržaj
- Početna/hero sekcija
- Opis kluba i aktivnosti
- Primjeri projekata
- Kontakt forma s osnovnom JavaScript validacijom
- Mobilna navigacija i prilagodljiv raspored
- Wireframe i mockup u `docs/`

## Pokretanje
Preuzmi ili kloniraj repozitorij i otvori `index.html` u web pregledniku. Nije potrebna instalacija dodatnih paketa. Google Fonts zahtijeva internet; stranica i bez njih koristi zamjenske fontove.

## Struktura
- `index.html` — sadržaj i sekcije stranice
- `style.css` — boje, raspored i prilagodba za mobilne ekrane
- `script.js` — mobilna navigacija, godina u podnožju i validacija forme
- `docs/wireframe.svg` — skica rasporeda
- `docs/mockup.svg` — vizualni prijedlog
- `docs/izvjestaj.md` — nacrt izvještaja koji treba provjeriti i dopuniti

## Važna napomena
Kontakt forma samo provjerava unos i prikazuje potvrdu u pregledniku. Ne šalje podatke na email niti ih pohranjuje. Projekti i klub na stranici predstavljeni su kao primjeri; prije javne upotrebe dopuni ih stvarnim informacijama uz dozvolu škole.
